# Les Amis de Monsieur Croche

Site de Charles Cabral, pianiste, musicologue et professeur de piano à Montpellier :
cours de piano, salons musicaux commentés, lectures musicales.

Site statique (HTML + CSS) publié avec GitHub Pages : https://lesamisdemonsieurcroche.github.io

## Structure

- `index.html` : page d'accueil
- `cours.html` : cours de piano
- `a-propos.html` : présentation
- `assets/style.css` : mise en forme (palette « Partition ancienne », polices Playfair Display + Lato)
